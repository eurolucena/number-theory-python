# Number Theory with Python

Computational experiments and educational implementations in number theory using Python.

## About this project

This repository collects Python implementations of classical algorithms and computational experiments in elementary and computational number theory.

The main goals are:

- to illustrate mathematical concepts through computation;
- to implement classical algorithms in a clear and readable way;
- to explore numerical patterns and conjectures experimentally;
- to provide examples useful for teaching and mathematical experimentation.

## Planned topics

- Euclidean algorithm
- Extended Euclidean algorithm
- Divisibility and greatest common divisors
- Modular arithmetic
- Prime numbers
- Basic primality tests
- Digital roots
- Mersenne numbers
- Fermat numbers
- Computational experiments in number theory

## Tools

- Python 3
- Jupyter Notebook (for selected experiments)
